  • 노란 칸에 적으면 바로 저장됩니다.
  • 코스 칸에는 그 코스 9홀 합계를 적습니다. (코스 수는 '대회 설정'에서)
  • 방향키(↑↓←→)로 칸을 옮깁니다. Enter를 누르면 아래 칸으로 갑니다. 빨간 줄은 확인이 필요합니다.
  • 칸 제목(⇅ 표시)을 누르면 정렬됩니다. 여러 칸을 차례로 누르면 누른 순서(①②)대로 정렬합니다. 같은 제목을 다시 누르면 거꾸로, 한 번 더 누르면 빠집니다.
  • 초록 점수 칸은 단체전 팀 점수로 쓰인 점수(그 코스 팀원 중 최저타)입니다.
